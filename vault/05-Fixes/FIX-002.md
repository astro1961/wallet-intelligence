# FIX-002 — Fallback выбора сети

## Причина (RU)
`SyncEngine._resolve_network` при отсутствии явной сети и WalletNetwork делал fallback:
```python
select(Network).where(Network.enabled == True).order_by(Network.id)
```
и вызывал `.scalar_one_or_none()`, который бросает `MultipleResultsFound`, если enabled-сетей > 1.

## Изменение
- Файл: `app/core/sync_engine.py`
- `.scalar_one_or_none()` → `.scalars().first()` (берём первую enabled-сеть).

## Проверка
- Тест: `tests/unit/test_sync_engine.py::test_resolve_network_fallback_with_multiple_enabled`
- Результат: [[RUN-20261109-005]] — sync 8/8 ok, 8 снимков.

## Саммари (RU)
Одна строка фикса вернула синхронизацию: балансы кошельков теперь сохраняются и отображаются.

## Выводы (RU)
- `scalar_one_or_none()` уместен только когда строк действительно 0 или 1; для «первой из многих» — `.scalars().first()`.
