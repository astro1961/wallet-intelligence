# FIX-001 — Dashboard обновляет панель при возврате

## Причина (RU)
При возврате на уже смонтированный экран Textual посылает событие `ScreenResume`, а не `Show`.
Обработчик был повешен на `on_show`, поэтому `refresh_data()` не вызывался и панель показывала
устаревшие данные.

## Изменение
- Файл: `app/ui/screens/dashboard.py`
- Метод `on_show` заменён на `on_screen_resume` (тот же вызов `refresh_data()`).

## Проверка
- Тест: `tests/e2e/test_wallet_add_flow.py::test_wallet_add_flow`
- Результат: [[RUN-20261109-002]] — 13/13 E2E passed.

## Саммари (RU)
Дефект устранён заменой хука жизненного цикла на корректный для `switch_screen`. После добавления
кошелька и возврата на Dashboard панель сразу показывает кошелёк без ручного обновления.

## Выводы (RU)
- Для экранов Textual, на которые возвращаются через `switch_screen`, нужен `on_screen_resume`,
  а не `on_show`.
- E2E-тест закрепляет поведение как регрессию.
