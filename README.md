# Wallet Intelligence Tracker (WIT)

Локальная консольная утилита (TUI) для структурирования, мониторинга и анализа публичной ончейн-активности криптовалютных кошельков, DeFi-позиций, проектов и тестнетов.

> **Текущий этап разработки:** **Этап 1B (Textual TUI Shell) завершён**. Доступен терминальный интерфейс с рабочей навигацией по всем 9 разделам, статус-баром, счётчиками базы данных, горячими клавишами и адаптивностью под компактные терминалы (60×20). CRUD, провайдеры и синхронизация запланированы на последующие этапы.

## Безопасность и Read-Only режим

- **Только чтение:** приложение работает строго в режиме **read-only** по отношению к блокчейнам.
- **Никаких приватных ключей:** хранение seed-фраз, приватных ключей, подписание или отправка транзакций категорически запрещены и не поддерживаются архитектурно.
- **Локальное хранение:** база данных SQLite (`data/wallet_tracker.db`) хранится исключительно локально на вашем компьютере.
- **Защита секретов:** API-ключи провайдеров задаются только через переменные окружения (`.env`), никогда не попадают в git, `config.yaml` или лог-файлы.

## Требования

- Python 3.12+
- Диспетчер пакетов [uv](https://github.com/astral-sh/uv)

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <repo_url>
   cd wallet-intelligence
   ```

2. Установите зависимости через `uv`:
   ```bash
   uv sync
   ```

3. Настройте переменные окружения:
   ```bash
   cp .env.example .env
   # При необходимости укажите ETHERSCAN_API_KEY, BLOCKSCOUT_API_KEY и др.
   ```

## Конфигурация и окружение

Основная конфигурация задаётся в файле `config.yaml`:
- `app`: параметры приложения (название, интервал автообновления в секундах, таймзона);
- `database`: путь к локальной БД SQLite (`path: data/wallet_tracker.db`);
- `providers`: настройки провайдеров (Etherscan, Blockscout, DeFiLlama) с указанием имён env-переменных (`api_key_env`);
- `networks`: список поддерживаемых EVM-сетей (Ethereum, Arbitrum, Optimism, Base, BNB Chain, Polygon, Sepolia) с RPC и ссылками на обозреватели.

Переменные окружения (`.env`):
- `WIT_CONFIG` — переопределение пути к `config.yaml`;
- `WIT_DB_PATH` — переопределение пути к базе данных SQLite;
- `WIT_REFRESH_INTERVAL` — переопределение интервала обновления данных;
- `LOG_LEVEL` — уровень логирования (`INFO`, `DEBUG`, `WARNING`, `ERROR`).

## Запуск TUI интерфейса

Для запуска терминального интерфейса выполните:

```bash
uv run python main.py
# или через зарегистрированную CLI-точку входа
uv run wallet-intelligence
```

Дополнительные параметры CLI:
```bash
uv run python main.py --help
uv run python main.py --config config.yaml --db data/wallet_tracker.db --log-level INFO
uv run python main.py --version
```

## Таблица горячих клавиш (TUI Hotkeys)

Интерфейс поддерживает управление как с клавиатуры, так и кликами мыши по элементам сайдбара.

| Клавиша | Раздел / Действие | Назначение в Этапе 1B |
|---|---|---|
| `1` | Dashboard | Переход на главный экран со сводными счётчиками из БД |
| `2` | Wallets | Переход в раздел кошельков (empty state) |
| `3` | Activities | Переход в раздел ончейн-активностей (empty state) |
| `4` | Projects | Переход в каталог проектов и тестнетов (empty state) |
| `5` | DeFi | Переход в раздел DeFi-позиций (empty state) |
| `6` | Networks | Переход в управление сетями и RPC (empty state) |
| `7` | Graph | Переход к графу связей (empty state) |
| `8` | Import | Переход в мастер пакетного импорта (empty state) |
| `9` | Settings | Переход в настройки приложения (empty state) |
| `↑` / `↓` | Сайдбар | Перемещение курсора по списку разделов |
| `Enter` | Выбор | Открытие выделенного в сайдбаре раздела |
| `Esc` | Домой / Назад | Возврат на экран `Dashboard` (позже: закрытие диалогов) |
| `q` | Выход | Завершение работы приложения |
| `r` | Обновить | Обновление времени в статус-баре и счётчиков (Синхронизация — Этап 4) |
| `a` | Добавить кошелёк | Уведомление о реализации в Этапе 2 |
| `i` | Импорт | Уведомление о мастере импорта в Этапе 2 |
| `f` | Фильтры | Уведомление о фильтрах в Этапе 2 |
| `g` | Открыть граф | Уведомление о графе NetworkX в Этапе 7 |
| `/` | Поиск | Уведомление о глобальном поиске в Этапе 2 |

> **Примечание:** горячие клавиши автоматически блокируются при нахождении фокуса в текстовых полях ввода (`Input`, `TextArea`).
