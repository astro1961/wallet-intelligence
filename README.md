# Wallet Intelligence Tracker (WIT)

Локальная консольная утилита (TUI) для структурирования, мониторинга и анализа публичной ончейн-активности криптовалютных кошельков, DeFi-позиций, проектов и тестнетов.

> **Статус:** все 8 этапов реализованы и приняты. Полный TUI с 9 разделами, CRUD кошельков/групп/тегов, пакетный импорт (CSV/TXT/JSON), EVM-провайдеры (Blockscout, Etherscan, JSON-RPC с фолбэком), инкрементальная синхронизация с паузой/резюмом, Activity Tracker, каталог проектов, DeFi-анализатор, граф связей (NetworkX), Solana-адаптер и резервное копирование БД.

## Безопасность и Read-Only режим

- **Только чтение:** приложение работает строго в режиме **read-only** по отношению к блокчейнам.
- **Никаких приватных ключей:** хранение seed-фраз, приватных ключей, подписание или отправка транзакций категорически запрещены и не поддерживаются архитектурно.
- **Локальное хранение:** база данных SQLite (`data/wallet_tracker.db`) хранится исключительно локально на вашем компьютере.
- **Защита секретов:** API-ключи провайдеров задаются только через переменные окружения (`.env`), никогда не попадают в git, `config.yaml` или лог-файлы.

## Требования

- Python 3.12+
- Диспетчер пакетов [uv](https://github.com/astral-sh/uv)

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <repo_url>
   cd wallet-intelligence
   ```

2. Установите зависимости через `uv`:
   ```bash
   uv sync
   ```

3. Настройте переменные окружения:
   ```bash
   cp .env.example .env
   # При необходимости укажите ETHERSCAN_API_KEY, BLOCKSCOUT_API_KEY и др.
   ```

## Конфигурация и окружение

Основная конфигурация задаётся в файле `config.yaml`:
- `app`: параметры приложения (название, интервал автообновления в секундах, таймзона);
- `database`: путь к локальной БД SQLite (`path: data/wallet_tracker.db`);
- `providers`: настройки провайдеров (Etherscan, Blockscout, DeFiLlama) с указанием имён env-переменных (`api_key_env`);
- `networks`: список поддерживаемых сетей (Ethereum, Arbitrum, Optimism, Base, BNB Chain, Polygon, Sepolia) с RPC и ссылками на обозреватели.

Переменные окружения (`.env`):
- `WIT_CONFIG` — переопределение пути к `config.yaml`;
- `WIT_DB_PATH` — переопределение пути к базе данных SQLite;
- `WIT_REFRESH_INTERVAL` — переопределение интервала обновления данных;
- `LOG_LEVEL` — уровень логирования (`INFO`, `DEBUG`, `WARNING`, `ERROR`).

## Запуск TUI интерфейса

Для запуска терминального интерфейса выполните:

```bash
uv run python main.py
# или через зарегистрированную CLI-точку входа
uv run wallet-intelligence
```

Дополнительные параметры CLI:
```bash
uv run python main.py --help
uv run python main.py --config config.yaml --db data/wallet_tracker.db --log-level INFO
uv run python main.py --version
```

## Миграции базы данных

База данных и схема создаются автоматически при первом запуске приложения.
Также поддерживается ручное управление миграциями через Alembic:

```bash
# Применение миграций
uv run alembic upgrade head

# Создание новой миграции
uv run alembic revision -m "description"
```

## Резервное копирование

Модуль `app/core/backup.py` предоставляет согласованный снапшот БД и восстановление:

```python
from app.core.backup import backup_database, restore_database, verify_database

info = backup_database(engine, "data/backup.db")   # {'sha256', 'size_bytes', 'table_count', ...}
restore_database(engine, "data/backup.db")
verify_database(engine)                            # PRAGMA integrity_check
```
