# TASK — Dashboard в стиле netwatch (плотный мониторинговый TUI)

Переработать **только** `app/ui/screens/dashboard.py` в плотный multi-panel дашборд
в духе `netwatch`/`btop` (мониторинговый TUI). Остальные экраны (`wallets.py`,
`activities.py`, `defi.py`, `graph.py`, `networks.py`, `projects.py`, `settings.py`,
`import_wallets.py`) **не трогать**.

## Ссылка на стиль (netwatch)
Плотный data-dense дашборд: верхняя строка сводных big-numbers, ниже несколько
тайловых панелей (таблицы + лента + прогресс-бар), цветовые метки ▲/▼ (зелёный рост,
красный падение), зум панелей клавишами 1–4, сортировка, статус-строка внизу.

## Требования к `DashboardScreen`

### 1. Верхняя панель — сводные метрики (big numbers)
Один горизонтальный ряд: `TOTAL BALANCE`, `WALLETS`, `TRACKED TX`, `DEFI POS`,
`LAST SYNC`. Крупные значения; для `TOTAL BALANCE` и изменений — цветовая метка
`▲ +x%` (зелёный) / `▼ -x%` (красный) / `—` (серый) при отсутствии данных.

### 2. Панель WALLETS (таблица, сорт/fold)
Колонки: `ADDRESS` (сокращённый, `shorten_address`), `BALANCE` (формат токена),
`CHANGE 24h` (▲/▼ цветной %), `NETWORK`. Сортировка по балансу и по изменению
(клавиша), fold групп (свернуть/развернуть).

### 3. Панель RECENT ACTIVITY (лента)
Последние `Activity` из БД: `time · address · тип · сумма` с цветовой меткой по типу
(transfer/sell/claim/bridge/swap и т.п.).

### 4. Панель BALANCE TREND
Прогресс-бар / спарклайн изменения совокупного баланса за период (на основе
`BalanceSnapshot`), с % насыщения (как saturation bar в netwatch).

### 5. Зум панелей (1–4)
Клавиши `1`–`4` переключают фокус/увеличивают одну из четырёх панелей
(метрики / wallets / activity / trend). Повторное нажатие возвращает полный вид.

### 6. Статус-строка внизу
`sync: <idle|syncing|paused> · <время>` + блок issues (число ошибок RPC/провайдера,
если есть). Существующие hotkeys (`s` sync/pause, `p`, `/`, `r`, `q`) сохранить.

### 7. Цветовая схема
Тёмный фон, зелёный/красный/жёлтый/акцент — через Textual CSS (переменные цвета),
моноширинно, компактно (без пустых строк-раздува).
