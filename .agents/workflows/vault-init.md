# /vault-init — проверка хранилища

1. Собери все wiki-links `[[...]]` во всех `.md` vault.
2. Проверь, что каждая ссылка ведёт на существующий файл; список битых — в отчёт.
3. Найди баги со `status: open|in-progress`, у которых `fix: null` → список.
4. Найди фиксы без `verified_by` → список.
5. Проверь, что у каждого `RUN-...` есть `status` и русские блоки Саммари/Выводы.
6. Обнови `00-Home.md` (open_bugs) по факту.
7. Отчёт: таблица проблем + рекомендации, в конце блоки **Саммари (RU)** и **Выводы (RU)**.
